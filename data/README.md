# Data

The experiment dataset is **simulated** — generated by the seeded script
[`../src/generate_data.py`](../src/generate_data.py) — with known ground
truth (control conversion 12.0%, treatment lift +1.5pp, ~50,000 users/arm).
It does not come from any real company or real users. See the main README
for why known ground truth is a deliberate design feature of this project
(it makes the simulation audit in notebook Section 6 possible).

## Generate it

```bash
python -m src.generate_data
```

This writes `experiment.csv` (100,000 rows) into this directory. The CSV is
gitignored — regenerate it from the seed rather than committing data files.
The notebook also regenerates it automatically if the file is missing.

## Schema

| Column | Description |
|---|---|
| `user_id` | Unique user identifier (1–100,000) |
| `arm` | `control` or `treatment`, assigned 50/50 |
| `user_type` | Segment: `new` or `returning` |
| `device` | Segment: `mobile` or `desktop` |
| `prior_sessions` | Sessions in the 30 days **before** the experiment (pre-experiment covariate used by CUPED; correlated with conversion, ρ ≈ 0.24) |
| `converted` | Primary metric: 1 if the user completed checkout, else 0 |

## How the ground truth is built

Each user's conversion probability is `base + slope × prior_sessions +
segment bonuses`, clipped to a sane range, with exactly **+0.015** added for
treatment users. The observed effect therefore hovers around +1.5pp (this
run: +1.53pp) rather than equaling it — sampling noise included, like a
real experiment.
